# Analise Pontos de Função - Neuro Vita

## 📌 Objetivo do Projeto

Representar a precificação de cálculos de cada tela formalizada e alinhamento de escopo para o desenvolvimento do Neuro Vita.  Cada tela foi calculado de acordo com a complexidade das Funções de Dados (Arquivos Lógicos Internos - ALI e Arquivos de Interface Externa - AIE) e Funções de Transação (Entradas Externas - EE, Saídas Externas - SE e Consultas Externas - CE).

## ⚙ Atribuição de pesos - Tabela de Referência

Função:

ALI: Complexidades (Baixa = 7, Média = 10, Alta = 15)
AIE: Complexidades (Baixa = 5, Média = 7, Alta = 10)
EE: Complexidades (Baixa = 3, Média = 4, Alta = 6)
SE: Complexidades (Baixa = 4, Média = 5, Alta = 7)
CE: Complexidades (Baixa = 3, Média = 4, Alta = 6)
